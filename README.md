# Controle-Solicitações-SCM

Projeto didático para prática de gerenciamento de configuração com Git e GitHub

## Sobre o projeto
Pequeno sistema em Python para o time de operações registrar e listar chamados (solicitações de ajuste no sistema).

## Artefatos
- README.md: documentação do projeto
- chamados.py: código para abrir e listar chamados

## Como executar
python chamados.py
